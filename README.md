# Paisa — Expense Tracker

A simple, fast expense tracker built with plain HTML, CSS and JavaScript (no build step).

## Features
- Add and delete expenses with title, amount, date and category
- Monthly or all-time totals in ₹ (Indian number format)
- Category split bar with legend
- Data saved in the browser (localStorage), nothing leaves your device
- Export all expenses to CSV
- Responsive, with automatic dark mode

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
Push to GitHub, then import the repo on [vercel.com/new](https://vercel.com/new). No settings needed: Framework Preset "Other", no build command.
